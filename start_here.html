Bottleneck Risk Telemetry

Path Risk Notes
Loop → Strategy LOW In-memory fast math
Signal → Confluence MED Large lookback S/R
Execution → MT5 HIGH Network / Broker API
SLTP → Modify MED MT5 timeout potential

Race Condition Safeguards

SLTP vs Trailing Stop: trailing_stop updates in-memory state only; dynamic_sltp dispatches MT5 modifications.
Adoption vs Signal Execution: magic_number validation prevents re-adopting system-originated positions.
Database Concurrency: SQLite WAL mode + connection pooling prevents writer lock contention.
